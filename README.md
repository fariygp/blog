# 📝 Mindscape - Personal Blog Platform

A complete, responsive blog frontend with commenting system, category filtering, and contact form.

## Features
- Responsive design for all devices
- Blog post listing with category filter
- Single post view with comment system (LocalStorage)
- Newsletter subscription (demo)
- Contact form with message storage
- Mobile-friendly navigation

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript ES6
- LocalStorage API

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
3. Explore posts and leave comments!

## Live Demo Features
- Filter posts by category (Tech, Lifestyle, Productivity)
- Add comments to any post
- Subscribe to newsletter (demo alert)
- Send contact messages (saved to localStorage)
